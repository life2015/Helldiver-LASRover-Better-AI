## 源码、构建与安装的区别

`src/`是当前逻辑，`scripts/`是构建/部署/观察工具，`tests/`是隔离验证。发布包身份看`build/package-matrix.json`和各渠道报告；安装身份看部署记录及当次进程日志。本次半径调整前实际安装为0.7.5 v15 HUD独立模块，配合官方v15加载器及EATAirburst；以build/deployment.json为准。0.7.7已部署为v15 HUD，标记优先待新进程验收；此前0.7.6已确认请求运行，状态见[适配记录](game-update-25327279.md)。

包内说明以各自构建时快照为准。文档发生分歧时先核对源码、具体包和证据，不仅凭文档地址写内存。

同级`research/rover-investigation.md`为历史流水，`research/artifacts/`是原工作区的私有采样和反汇编材料；公开维护者不必持有这些个人文件。当前还有同级工具依赖、许可与独立发布流程待整理。
