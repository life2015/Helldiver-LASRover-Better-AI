## 实现边界

运行时按EXE与DLL完整哈希对选择显式布局配置，再校验该配置的关键机器码和既有对象身份/边界。未命中新配置时沿用旧布局的签名校验，不在游戏里扫描并猜测可写地址。配置覆盖snapshot的管理器根、实体归属字段、Behavior stride/ID，position的EXE根及HUD字体资源根；0.7.4索敌策略和内存写入字段种类不变。

原版本使用默认布局，历史基线依据保留在[runtime-layout.md](runtime-layout.md)。日志新增layout_id。外部观察器允许这两个已登记的模块组合并检查对应签名，仍只申请VM_READ，不写游戏。
