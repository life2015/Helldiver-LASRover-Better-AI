# 版本变更摘要

截至2026-09-23，当前源码版本为0.7.14。版本条目说明实现变化，不等于每项已通过实机验收；证据详见[验证记录](validation.md)。v12/v14/v15是加载器渠道，不是索敌算法版本。

0.7.14：有效标记替代目标独立触发原生重选，无需等待普通攻击或旧目标未攻击计时；保留节点6/7、已有目标、实时身份/候选资格、Recent及事务校验。标记请求最短间隔0.5秒，租约仍0.25秒；当前已锁定标记的4/3/5秒和1.5秒评分宽限不变。HUD增加等待原因。仅实现可选标记主动转火，未实现零评分刷新或缺失候选重建。

0.7.13：标记存在与可攻击资格分离；已锁定且此前有效的同一目标，单独评分失效时最多宽限1.5秒。保留4/3/5秒计时，不延长0.25秒写入租约，不给新选择放宽资格。HUD区分等待转火、暂不可选、宽限及标记结束；日志增加marker_reason、marker_notice、marked_grace_remaining。见[实现规则](marked-grace.md)。

0.7.12：近处优先阈值由30米调为20米，同步HUD标签及发行包说明；边界20米仍算圈内，当前目标已在圈内时按相邻目标选择。保留标记4/3/5秒及普通0.4/1.5/1.5秒计时。这不是射程上限。

0.7.11：仅当前有效标记目标使用4秒攻击窗口、3秒未攻击重选和5秒最长锁定兜底；普通目标保留0.4/1.5/1.5秒。标记失效立即恢复普通计时，刷新标记不清零；HUD/日志显示实际阈值和进度。185项Lua测试通过，实战效果待验证。

0.7.10：有效标记等待转火时，HUD顶部以绿色MARKED展示，第二行显示标记ID与等待/当前锁定状态；活动请求仍显示MOD索敌状态。沿用五行保留式绘制，索敌策略与0.7.9相同，No HUD不含此界面改动。

0.7.9：修正将HUD屏幕焦点位0x800当作玩家标记必要条件的错误；有效性复核忽略每帧重算的0x1c00屏幕状态位，继续核对归属、计时、目标身份和其他标志。178项Lua测试及35帧真实采样恢复回放通过，实机效果待验证。打包新增`--channels v14 v15`，未选v12时其中间包仅写入build/internal-base。
