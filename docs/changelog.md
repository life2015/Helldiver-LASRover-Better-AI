# 版本变更摘要

截至2026-09-19，当前源码/构建版本为0.7.4。版本条目说明实现变化，不等于每项已通过实机验收；证据详见[验证记录](validation.md)。v12/v14/v15是加载器渠道，不是索敌算法版本。

| 版本 | 主要变化 |
| --- | --- |
| 0.7.4 | 增加独立1.5秒同目标有效观察计时，避免攻击状态反复切换使转火窗口无限重置；按最近其他候选兜底，HUD/日志区分max lock；127项Lua测试通过，实战待验收 |
| 0.7.3 | 未进入同步攻击状态的重选等待从0.5秒延长至1.5秒；HUD与包内说明同步。正常0.4秒攻击轮换不变，状态交替导致计时重置的盲区仍存在 |
| 0.7.2 | 增加No HUD：不编入HUD，索敌与文本日志保留；一键生成v12/v14/v15各两种变体；v14/v15复用当前本体，已不再固定0.7.1 |
| 0.7.2命名调整 | 主名“激光狗索敌优化”；全部明确标注v12/v14/v15与“内置加载器”或“需要额外安装加载器”；管理器显示名同步；No HUD后缀保留 |
| 0.7.1 | 请求恢复后绿/黄标题额外显示0.5秒并标注(last)，不延长实际请求 |
| 0.7 | 普通转火按当前目标附近排序；从15米外转火时优先圈内；超时重选仍按距漫游车最近 |
| 0.6.1 | Next短请求结束后保留至提交满2秒，避免10Hz刷新错过；不表示仍锁定 |
| 0.6 | HUD顶部居中；Recent从8条/4秒改为1条/1秒；新增0.5秒未进入同步攻击状态的锁定超时重选 |
| 0.5.1 | HUD新增Locked/Next目标ID |
| 0.5 | 增加游戏内状态面板及独立绘图错误处理 |
| 0.4.1 | 整文件哈希变化可尝试运行；保留关键签名、结构及写入校验 |
| 0.4 | 最近目标优先及当时的8条/4秒历史；已被后续策略替代 |
| 0.3 | 启动暂时缺数据时等待重试；两组实战观察到活敌转火 |
| 0.1–0.2 | 原型启动、直接入口和阶段日志，发现早期数据未就绪问题 |

最初v14内置桥/v15 Addon曾基于0.7.1做独立验证，这些历史包保留供证据核对，当前发行选择以[六包清单](packaging-channels.md)为准。

新距离策略的实机收益、不同敌人/遮挡、联机所有权、长时间运行、No HUD实机表现与多Mod加载共存仍需记录。已有GPU错误与整机故障证据不足以确定Mod或驱动版本为根因；No HUD仅提供独立变体与对照条件，不作为已确认修复。
